# Laboratory 06 — Cloud Deployment Engineer

## Mission Overview
Deploy a two-tier private cloud storage system (Nextcloud + MariaDB) using
Docker Compose as Infrastructure as Code.

## Objectives
- Explain multi-tier application architecture
- Understand the structure of a `docker-compose.yml` file
- Create configuration files with the `nano` CLI editor
- Deploy a multi-container application with Docker Compose
- Document IaC principles in Markdown

## Commands Executed
-bash mkdir nextcloud-deployment, cd nextcloud-deployment, nano docker-compose.yml, cat docker-compose.yml, docker-compose up -d, docker-compose ps, docker-compose down,

## Skills Learned
Docker Compose, YAML, container networking and DNS-based service discovery,
environment-variable configuration, container lifecycle management.
