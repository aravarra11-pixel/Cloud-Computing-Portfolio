# Laboratory Activity 7
## Mission 7: The Cloud Operations Engineer

## Mission Overview

This laboratory activity focuses on monitoring Linux system resources and Docker containers. It also demonstrates how logs and real-time metrics can be used to check the health and performance of a web application.

## Objectives

- Monitor Linux memory, disk space, and CPU activity.
- Deploy an Nginx web server using Docker.
- Generate HTTP traffic using curl.
- Analyze Docker application logs.
- Monitor container CPU and memory usage.
- Document system observations using Markdown.

## Monitoring Commands Executed

The following commands were used during this laboratory:

```bash
free -h
df -h
top
docker run
curl
docker logs
