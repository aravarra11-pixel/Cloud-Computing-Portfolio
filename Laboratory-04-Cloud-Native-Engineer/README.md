# Laboratory 04 – The Cloud-Native Engineer

## Mission Overview

This laboratory activity focuses on understanding containerization and Docker. It includes a comparison between Virtual Machines and containers, deployment of an Nginx web server, and basic container lifecycle management.

## Objectives

- Differentiate Virtual Machines and containers.
- Execute basic Docker commands.
- Deploy an Nginx container.
- Manage the container lifecycle.
- Document Docker operations using Markdown.

## Docker Commands Executed

Docker commands used in this laboratory are documented in `docker-deployment.md`.

## Skills Learned

- Basic Docker CLI commands
- Container deployment
- Port mapping
- Nginx container management
- Container lifecycle management
- Markdown documentation
- GitHub documentation

## Challenges Encountered

One challenge was becoming familiar with Docker commands and understanding how containers work. I also had to understand how port mapping connects the host computer to the web server running inside the container.
