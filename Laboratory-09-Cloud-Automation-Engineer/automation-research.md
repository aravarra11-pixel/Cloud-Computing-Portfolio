# Automation Research

**Laboratory 09 – Cloud Automation Engineer**

## 1. Bash Script

A Bash script is a text file containing a series of Linux commands that can be executed automatically instead of typing each command manually. The `#!/bin/bash` line, called a shebang, tells the operating system to use the Bash interpreter when executing the script directly.

## 2. Variables

Variables are used in programming to store values such as directory paths, filenames, and timestamps. Using variables like `$BACKUP_DIR` makes a script easier to read, maintain, and modify because the stored value can be changed in one place instead of updating multiple commands.

## 3. Cron Job

A Cron job is a scheduled task in Linux that automatically executes a command or script at a specified time or interval. It is essential in cloud operations because it allows administrators to automate repetitive activities such as backups, system maintenance, and log management without requiring manual execution.

## Conclusion

Bash scripting, variables, and Cron jobs are important tools for Linux automation. Together, they help cloud engineers manage systems more efficiently, reduce repetitive work, and maintain consistent operations.
