# Automation Research

## 1. Bash Script

A Bash script is a file containing Linux commands that run in sequence to perform a task automatically. The line `#!/bin/bash` is called the shebang, and it tells the system which interpreter should run the script.

## 2. Variables

Variables store values such as folder paths and filenames so they can be reused throughout a script. For example, `$BACKUP_DIR` allows us to change the backup folder in one place instead of editing every command that uses it.

## 3. Cron Job

A cron job is a scheduled task in Linux that runs commands automatically at specified times. It is useful in cloud operations because it can automate repetitive tasks such as backups, maintenance, and log processing without requiring someone to start each task manually.
