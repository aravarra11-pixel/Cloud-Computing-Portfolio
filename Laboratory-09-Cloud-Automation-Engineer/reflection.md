# Mission 9 – Personal Reflection

**Laboratory 09: The Cloud Automation Engineer**

Throughout this laboratory activity, I learned how important automation is in managing cloud computing environments. When administrators handle hundreds or thousands of servers, performing repetitive tasks manually becomes difficult and time-consuming. Automation allows these tasks to be completed consistently, saves time, and reduces the possibility of human error.

However, I also realized that automation has potential risks. A small mistake in a script can cause serious problems, especially when the same script is executed across many servers. For example, an incorrect command that deletes important files could result in widespread data loss. This is why scripts should always be tested, reviewed, and verified before being deployed in production environments.

Writing a Bash script was different from creating a Docker Compose YAML file in Mission 6. Bash scripting focuses on executing commands and automating tasks, while Docker Compose uses YAML to define and configure containerized services. Both are useful in cloud computing, but they serve different purposes.

Looking back at Laboratory 1 through Laboratory 9, my understanding of cloud computing has developed significantly. At first, I thought cloud computing was mainly about storing information and accessing resources through the internet. As I completed the laboratory activities, I discovered that cloud computing also involves infrastructure management, containerization, security, monitoring, deployment, and automation.

Among the different roles introduced during the semester, I found the Cloud Automation Engineer role particularly interesting because it involves creating scripts that make repetitive tasks easier and more efficient. I enjoyed learning how a few Linux commands could be combined to perform an important task automatically.

Overall, this laboratory activity improved my understanding of Bash scripting, Linux permissions, backup operations, and Cron scheduling. It also taught me that successful cloud administration requires careful planning, testing, and continuous learning.
